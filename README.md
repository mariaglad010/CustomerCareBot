# telegram-reminder-bot

Telegram-бот для рабочей группы: админ настраивает напоминания командами в чате, бот по таймеру шлёт их в беседу. Хостинг — GitHub Actions (cron), состояние (список напоминаний, offset) хранится прямо в репозитории. Пояс — Europe/Moscow.

## Как это работает

Каждые 10 минут GitHub Actions запускает `src/bot.py`:

1. забирает новые сообщения из чата (`getUpdates`), обрабатывает команды админа;
2. проверяет, чьё напоминание наступило, и шлёт его в группу;
3. коммитит и пушит изменения состояния (`config.json`, `data/`) обратно в репозиторий.

Задержка отправки — до нескольких минут (ограничение cron Actions), для рабочих напоминаний это норм.

## Настройка (один раз)

### 1. Создать бота
- В Telegram открой [@BotFather](https://t.me/BotFather), команда `/newbot` → получишь **токен** вида `123456789:AA...`.
- Добавь бота в рабочую группу (в настройках группы → Add Members → найди своего бота).

### 2. Загрузить проект на GitHub
- Создай репозиторий, запуши этот проект, *включи* Actions (вкладка Actions → Enable).

### 3. Добавить секрет
- Repo → **Settings → Secrets and variables → Actions → New repository secret**
- Name: `TELEGRAM_BOT_TOKEN`, Value: токен из BotFather.

### 4. Назначить админа
Самый простой способ — с первого раза запустить workflow вручную:
- Repo → **Actions** → workflow `telegram-reminder-bot` → **Run workflow**.
- Затем в группе напиши боту команду `/claim` — отправивший станет админом, а чат привяжется автоматически (запишется в `config.json`).

Альтернатива — сразу прописать в `config.json`:
```json
{
  "admin_ids": [123456789],
  "target_chat_id": -1001234567890
}
```
(свой id узнаёшь командой `/id` в личке с ботом, id группы — добавь бота и тоже `/id`).

## Команды

| Команда | Описание |
|---|---|
| `/add "текст" 2026-09-15 14:00` | одноразовое напоминание |
| `/add "текст" ежедневно 09:00` | ежедневно |
| `/add "текст" каждый ПН 15:30` | по дням: ПН ВТ СР ЧТ ПТ СБ ВС |
| `/list` | список активных + следующая отправка |
| `/del N` | удалить запись N |
| `/clear` | убрать завершённые |
| `/help` | справка |
| `/id` | свои user-id/chat-id |

Полностью управлять могут только админ; `/list`, `/help`, `/id` — все.

## Локальный запуск (для теста)

```bash
pip install -r requirements.txt
TELEGRAM_BOT_TOKEN="токен" python src/bot.py
```

## Безопасность

- Токен живёт только в GitHub Secrets, в коде/коммитах его нет.
- fetch: `config.json` содержит только `admin_ids` и ID чата — не секреты.
